ALTERF WIDGET (tile style) - files
===================================
This zip holds the two files that make the tile layout:

  Alterf/Alterf.conf            -> the conky config
  Alterf/scripts/card.lua       -> draws all tiles, text and images

They go on top of the original Alterf conky theme (which supplies the
res/, fonts/ and scripts/ folders: avatar, fonts, weather and wifi scripts).
Full step-by-step instructions are in Alterf-Install-Guide.pdf.
